# Third-party code

model3recomp is MIT licensed. The sound board carries code from elsewhere,
under the licences below; each file keeps its own notice.

| Where | What | Licence |
|---|---|---|
| `src/m68k/` | [Musashi](https://github.com/kstenerud/Musashi) 4.60, Karl Stenerud's 68000 emulator, built for the 68000 only. `m68kops.c` / `.h` are generated by its `m68kmake`; `m68kconf.h` is configured for this project. | MIT -- `src/m68k/LICENSE` |
| `src/m68k/softfloat/` | SoftFloat 2b, John R. Hauser, as packaged with Musashi. Linked because Musashi's FPU code refers to it; a 68000 never executes it. | SoftFloat licence -- `src/m68k/softfloat/README.txt` |
| `src/scsp.c` | A C port of MAME's `scsp.cpp` and `scspdsp.cpp` (ElSemi, R. Belmont, kingshriek). | BSD-3-Clause -- the notice at the top of the file |
| `src/sound.c` | The sound board's wiring follows MAME's `sega/model3.cpp` (R. Belmont, Ville Linde). | BSD-3-Clause |

Supermodel (GPL) is used as a reference for how the hardware behaves; no
code from it is included.
